## 🕹️ Features  
- **Simple Controls**: Easy to learn and play.  
- **Fast-Paced Action**: Engage in quick shooting challenges.  
- **Web-Based**: Play anytime, anywhere without installation.  
- **Engaging Design**: Smooth animations and interactive elements.  

## 🚀 How to Play  
1. Open the game in a web browser.  
2. Aim and shoot at the targets.  
3. Score points by hitting the targets accurately.  
4. Compete for the highest score!
